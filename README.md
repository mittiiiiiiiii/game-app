##　アプリを作成
- フォルダ構造を整理
- すべての画面で共通となるコンポーネントを実装
- スタイルの変更を検知するテストコードを実装
- スタートページの実装
    - スタート画面のtestコードを作成
    - スタイルを実装
    - ゲーム画面への遷移機能を実装
- ゲームページの実装
    - ゲームページのコンポーネントを配置
    - ボタンをおしてスタートページへ戻る機能を実装
    - ゲーム機能を実装
- リザルトページの実装
    - ゲームページのコンポーネントを配置
    - スタートページに戻る機能を実装
- テストコードの実装
    - スタイルの変更を検出
        - 全コンポーネントのモックをでのテストを実装
    - Start コンポーネント
        - 正しくレンダリングされるかテストする機能を実装
        - プレイボタンが存在するかテストする機能を実装
    - Game コンポーネント
    - Result コンポーネント
